## 总结

r2 的三类实现问题中，DSH AK/SK 漏检和 spec 外显式错误码已经修复；Query Broker 与授权拒绝现在也有可关联的最小结构化应用日志。生命周期、回调认证/绑定/幂等/不可回退和双 surface 404 均有通过的定向测试。

仍有一项 Task 13.2 自动证据缺口：现有执行路径测试虽然扫描成功、执行器不可用、超时、数据源失败和结果失败的结构化日志与审计参数，但把 `repo.add_audit_log` 替换成内存函数，没有读取持久审计表；编译失败测试又没有捕获或扫描应用日志。真实 SQLite 跨面扫描仍只覆盖 queued 浏览器响应、非法 assertion 日志和早期审计。因此，用户明确要求的“success/compilation/unavailable/timeout/source/result failure 的应用日志与持久审计”尚未被一个实际持久化自动门禁完整覆盖。该问题不否定当前生产写入点，但不满足 Task 13.2 的回归验收，定为 P2。

### P1

### P2

1. **执行全路径自动敏感扫描没有验证持久审计，且遗漏编译失败应用日志。** `dic-be/tests/test_data_query_execution_audit.py` 的终态参数化测试用 monkeypatch 把 `query_broker.repo.add_audit_log` 替换成内存 `events.append()`；它验证的是传给仓储的 `detail_json`，不是 SQLite 中经 `repo.add_audit_log()` 最终二次脱敏后实际持久化的 `QueryAuditLog`。同文件的编译失败测试只检查 mock 审计参数，不设置 `caplog`、不读取结构化日志，也没有调用 `assert_no_sensitive_content` 扫描编译失败日志。`test_data_query_task13_security.py::test_sensitive_scan_covers_actual_http_logs_and_persisted_audit` 虽然使用真实 FastAPI/SQLite，但只扫描创建会话、创建轮次、queued GET、非法 assertion 日志及早期审计，没有驱动 Query Broker 的 success/compilation/unavailable/timeout/source/result failure。结果是 Task 13.2 明确要求的应用日志与持久审计跨面自动门禁仍不完整；仓储最终脱敏或编译失败日志若以后回归，当前组合仍可能全绿。

   **要求的修复证据：** 使用真实 SQLite 仓储（最好经真实 FastAPI Query Broker 路径，或至少真实 `repo.add_audit_log`）逐项驱动 success、compilation failure、executor unavailable、timeout、source failure、provider/result validation failure；对每项同时捕获 `security_detail` 应用日志、查询 `QueryAuditLog.detail_json`，用同一只报告类别的扫描器检查，并断言同 turnId、安全 jobId（适用时）和稳定 errorCode 可关联。保留现有五类真实 HTTP 前置拒绝和 fake adapter 零调用断言。

## 其它核验说明

- DSH scanner 的失败面只返回类别；本轮动态输入没有出现在输出中。
- `query_broker.py` 不记录编译产生的 SQL、异常文本或结果矩阵；日志与审计仅含语义编码、耗时、行数、结果字节、稳定码和白名单 jobId。
- 授权拒绝审计已包含 dataset、metric、dimension、filter dimension、time-range dimension、order-by field 和原因码；r1 的适用字段缺口保持修复。
- callback receiver 在读 body 前校验固定 workload identity 和 bearer，随后执行严格 body/大小/字段校验；业务主体、conversationId、turnId 三重绑定后才迁移状态。
- `turn_callback.py` 对同值回放返回当前投影，对终态后的 `running` 安全幂等，对其它冲突/逆向迁移返回不可枚举的失败；public browser 只能读取归属自己的轮次。
- 前端扫描器从 Vite manifest 递归扫描问数页面可达 JS chunks；真实 test-mode build 后 scanner 退出 0。
